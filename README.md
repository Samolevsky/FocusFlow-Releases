# FocusFlow downloads

FocusFlow is a Kanban task manager for organizing projects, boards, tasks, and subtasks.

## Download

**[Download the latest release](https://github.com/Samolevsky/FocusFlow-Releases/releases/latest)**

Choose the installer for your computer:

- **macOS (Apple Silicon and Intel):** `FocusFlow-<version>-mac-universal.dmg`
- **Windows (64-bit):** `FocusFlow-<version>-win-x64.exe`

[All releases](https://github.com/Samolevsky/FocusFlow-Releases/releases) · [Use FocusFlow in your browser](https://focusflow.samolevsky.com/)

## Installation notes

Current installers are unsigned, and the macOS application is not notarized. macOS Gatekeeper and Windows SmartScreen may warn or block installation. Automatic updates are not configured; download a new installer from this repository when updating. Back up your data before upgrading.

## About this repository

This repository contains public installers and release notes only. Application source is maintained separately and is not published here. GitHub's automatically generated source archives contain this downloads repository, not the application source.
